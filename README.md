ShopZone – E-Commerce Web Application

About the Project
ShopZone is an e-commerce web application developed using Java Spring Boot. It provides REST APIs for managing products, categories, sellers, users and shopping cart operations.

Technologies Used
- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- HTML
- CSS
- JavaScript
- Postman
- Maven

Features
- Product Management
- Category Management
- Seller Management
- User Management
- Shopping Cart Management
- REST API Development
- MySQL Database Integration
- Product Image Display

How to Run the Project
1. Clone this repository.
2. Import the project into Eclipse as an Existing Maven Project.
3. Create a MySQL database named "shopzone".
4. Configure your own database credentials and API keys in your local "application.properties".
5. Run the Spring Boot application.
6. Open http://localhost:8080/index.html in your browser.

API Testing
REST APIs are tested using Postman.
